# Security policy

## Supported version

Security fixes are applied to the current `main` branch and its scheduled data pipeline.

## Reporting a vulnerability

Use GitHub's **Security → Report a vulnerability** form for this repository. Please do not open a public issue for a suspected vulnerability.

Include the affected scraper, workflow, or data-processing component, reproduction steps, impact, and a minimal proof of concept. Do not include authentication tokens, scraped personal data, or other secrets. We will acknowledge a complete report within three business days and coordinate disclosure after a fix is available.
